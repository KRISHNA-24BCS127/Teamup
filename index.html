Teamup 🤝

A hackathon-built platform that helps students and developers find the right teammates for their projects — based on skills, interests and goals.

HTML/CSS/JS Node.js + Express MongoDB Team of 3
View Source on GitHub Documentation

✨ Features

🔐 Authentication

Signup, login and logout with profile management for every user.

🔍 Teammate Discovery

Search and filter potential teammates by skills, so you always find the right fit.

📄 Resume Parsing

Upload your resume (PDF/DOCX) and let Teamup extract your skills automatically.

🐙 GitHub Integration

Link your GitHub profile to showcase real projects to potential teammates.
